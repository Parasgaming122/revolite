Required motion effects:

- Custom cursor: small red dot + larger hollow circle

follower that trails with magnetic pull effect on

hover over buttons

- Hero canvas: animated particle field using vanilla JS

canvas — 200+ particles with red accent color,

connecting lines between nearby particles, mouse

repulsion effect, slowly drifting movement

- Smooth page load sequence: staggered reveal of each

hero element with GSAP timeline

- Scroll-triggered section reveals: every section

animates in with staggered children using ScrollTrigger

- Horizontal scroll ticker: infinite marquee with brand

services text on red background

- Portfolio cards: 3D tilt effect on mouse move using

JS perspective transform, glassmorphism overlay reveals

on hover, animated gradient border

- Services section: cursor reactive — subtle particle

burst at cursor position, cards expand with smooth

spring animation on hover, glowing red border appears

- Testimonials: smooth auto-rotating carousel with

momentum, manual swipe/drag support

- Numbers counter animation: stats count up when

scrolled into view

- Smooth scroll between all sections

- Parallax on hero title text at different speeds

- Morphing SVG shapes in background sections

- Text scramble effect on section headings

(characters randomize then settle into final text)

- Page transition overlay when clicking nav links

- Floating geometric shapes in About REVO-LITE banner

— animated rotation, scale pulsing, opacity breathing

TECHNICAL REQUIREMENTS

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Single HTML file, ALL CSS and JS embedded

- Load GSAP + ScrollTrigger from cdnjs

- Load Google Fonts: Cormorant Garamond + DM Sans

- Fully responsive — mobile first

- All animations GPU-accelerated (transform/opacity only)

- No layout shifts, no jank

- CSS custom properties for all colors

- SPA behavior — nav links smooth scroll to sections

- No frameworks — vanilla HTML/CSS/JS only

- Page must feel ALIVE at all times —

something is always subtly moving

- All images use onerror="this.parentElement.classList

.add('img-failed')" for graceful fallback
